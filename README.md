# Network-Automation-Skills
A dedicated repository to practice Networking and Networking Automation related skills


This project establishes a production-grade Cloud Engineering workflow that manages an Azure Virtual Machine and a Palo Alto firewall using Infrastructure as Code (IaC/Terraform) inside an automated GitHub Actions CI/CD pipeline. To protect your personal cloud budget and prevent unexpected billing surprises, the repository is integrated with Infracost. The moment you open a Pull Request to change your infrastructure setup, the automation workflow dynamically reads your configuration files, maps them to real-time global cloud catalogs, and automatically posts a line-by-line monthly cost breakdown directly as a comment into your GitHub tracking thread.
